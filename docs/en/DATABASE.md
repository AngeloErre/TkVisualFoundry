# DatabaseView

Add DatabaseView and open its component configuration. Choose SQLite, PostgreSQL or MySQL, the database/file, optional initial table and row limit. Remote connections also accept host, port and username. The password is requested at connection time or read from the configured environment variable; it is not stored in the project.

The runtime provides a data table and add, edit, delete and refresh actions. Use the code assistant for connection and CRUD snippets. Remote drivers are prepared through the dependency wizard. Try write operations on a test database first and use a table with a suitable primary key. Database permissions and schema constraints still apply.
