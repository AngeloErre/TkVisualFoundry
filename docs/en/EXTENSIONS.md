# External components

Use the component wizard or PyPI explorer to configure a component descriptor: module, class, supported properties and package requirements. Requirements are checked in the project interpreter before use. An installed package is not necessarily a compatible Tkinter widget; choose a class with an appropriate constructor and integration behavior.

Descriptors are stored with the project. Existing built-in components include optional adapters for multimedia, devices and databases. Generated code must run in an environment containing its required packages and native libraries.
