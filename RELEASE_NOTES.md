# VisualTk Studio 1.15

VB6-inspired workspace: left toolbox, central designer/code, right Project Explorer above Properties, compact icon toolbar and classic panel captions. Add object/event selectors, F7/Shift+F7, searchable categorized/alphabetical property rows, read-only identifiers and live geometry status.

Saved custom colors remain intact; View → VB6 Classic applies the new preset. Tooltips stay inside the main window without requesting keyboard focus.
