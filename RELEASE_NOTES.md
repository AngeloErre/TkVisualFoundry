# VisualTk Studio 1.12

Adds the library/theme manager, expanded ttk/CustomTkinter palette, tksheet/MapView/Pmw adapters and nested frame/tab containers. Provides isolated checks, project themes and deployment resource collection. Corrects CustomTkinter geometry handling.

Open Components → Libraries and themes. For nesting, select a container before inserting a widget, or set parent/page in the inspector. Use Visible page for tabs. The canvas preview remains schematic.

118 tests passed; 11 graphical tests skipped. Optional package imports and a native macOS modern-library app/ZIP build were verified. GUI execution and Windows builds remain pending. Tix is unavailable; PySimpleGUI, FreeSimpleGUI and guizero are cataloged as separate engines, without project generation in this release.
